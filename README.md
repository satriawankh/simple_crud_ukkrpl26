Langkah-langkah membuka di laptop:

1. Buka XAMPP Control Panel
3. Start Apache dan MySQL
4. Buat basis data sesuai dengan tutorial yang sudah diberikan
5. Masuk ke folder C/xampp/htdocs
6. Buat folder baru dengan nama ukk26
7. Buka Visual Studio Code, klik pada file kemudian pilih Open Folder
8. Cari lokasi C/xampp/htdocs kemudian pilih folder ukk26 dan klik Select Folder
9. Copy semua file dan kode yang ada di sini kemudian paste pada folder ukk26
10. Buka browser dan ketika localhost/ukk26
11. Akan muncul halaman login, masukkan username admin dan password admin.
